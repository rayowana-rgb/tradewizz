## BUG FIX: Simulation portfolio harga posisi tidak update → P/L salah (08:55 WITA)
User lapor harga barang yg dipegang di simulation portfolio tidak update, mempengaruhi P/L.

### Root cause
`engine.latest_price_cached()` (dipakai `_sim_price` untuk mark-to-market posisi) membaca cache period **"1mo"**. Daily warmer/screener HANYA me-refresh period **"1y"**. Jadi file cache "1mo" jadi BASI (mis. ARM last_bar 2026-06-19 close=439.46) sementara "1y" segar (2026-06-22 close=407.72). Akibatnya posisi pakai harga lama → unrealized P/L salah, dan banyak posisi tampak P/L=0 (last==avg krn keduanya basi sama).
Bonus: `engine.latest_price()` (live fallback) juga pakai "1mo" → sama basinya saat market tutup + TTL warm.

### Fix (app/engine.py)
- `latest_price_cached`: baca period "1y" dulu (sama dgn warmer), fallback ("1y","6mo","1mo"), ambil close non-NaN pertama yang >0.
- `latest_price`: ganti `_fetch(ticker,"1mo","1d")` → `"1y"`.
