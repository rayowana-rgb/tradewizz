# TradeWizz — GitHub Pages Website

Static marketing + legal website for **TradeWizz**, the AI-powered stock research and portfolio simulation app. Pure HTML + CSS — no React, no build step, no external dependencies, no tracking, no analytics, no cookies.

| File           | Purpose                                  |
| -------------- | ---------------------------------------- |

| `privacy.html` | Privacy Policy (Google Play & App Store) |
| `terms.html`   | Terms of Service                         |
| `support.html` | Support page + FAQ                        |

## Deploy to GitHub Pages

1. Create a **public** GitHub repository named `tradewizz`.
2. Upload `index.html`, `privacy.html`, `terms.html`, and `support.html` to the repository root.
3. Open the repository **Settings**.
4. Go to **Pages**.
5. Source: **Deploy from branch**.
6. Branch: **main**.
7. Folder: **/ (root)**.
8. Click **Save**.
9. Wait **1–5 minutes** for the first build.

### Expected URLs

- **Home:** https://rayowana.github.io/tradewizz/
